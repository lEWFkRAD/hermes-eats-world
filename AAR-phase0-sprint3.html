Key Lessons Learned

What Worked

  • Adversary board review caught real issues both times — T1: UWP/DPI/hang risk, T2: ctypes marshaling, off-by-one, recursion patterns
  • Python pivot was correct — uiautomation + mss proved pipeline in one session
  • Modular architecture enables incremental sprints — each module independently testable
  • Schema versioning from day one prevents downstream breakage
  • Bridge layer pattern cleanly separates TargetInfo models from raw uiautomation controls
  • T2 vision fallback covers Chromium/custom-rendered apps that T1 can't reach

What Didn't Work

  • C#/.NET SDK install failed in headless terminal — timeouts, GUI requirements
  • uiautomation API assumptions — SupportsPattern → GetPattern, GetRootElement → GetRootControl
  • ctypes marshaling — PostMessageW(str) doesn't auto-convert to LPCWSTR; need explicit c_wchar_p
  • OCR backend install — pytesseract not installed, tesseract-ocr binary missing. Using backend='none' fallback
  • FP rate on adversary reviews — 67% false positives, most were production concerns on spike POC

Open Questions

  • WebSocket server — Sprint 5 deliverable, no implementation yet
  • Orchestrator design — How to decompose goals into steps? Goal-directed vs reactive?
  • Verify module — Snapshot diffing exists in delta.py; needs formal verify module
  • WinRT Graphics Capture — Replace mss? Spec calls for WinRT, but mss works for MVP
  • Tesseract OCR — Requires system binary install (sudo apt install tesseract-ocr or Windows installer)
